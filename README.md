# Portale Familiare — prova PWA

Prototipo **pubblico e statico** per verificare l'installazione PWA su Android. Non contiene dati personali, credenziali, identificativi Google, URL della Web App o codice del portale privato.

## Pubblicazione

In **Settings → Pages**, selezionare **Deploy from a branch**, branch **main**, cartella **/(root)** e salvare. Aprire poi l'URL Pages da Chrome su Android e usare **Installa app** (se disponibile).

L'URL di Apps Script viene digitato dall'utente nel dispositivo, non salvato né trasmesso da questa pagina. L'apertura di Apps Script esce dallo scope della PWA: questo prototipo verifica il comportamento, **non** garantisce il portale a schermo intero.

Il repository è pubblico: non aggiungere segreti, dati personali o riferimenti al repository privato.
